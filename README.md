# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes resumes and compares them with job descriptions to calculate an ATS (Applicant Tracking System) compatibility score.

## 🚀 Features

- Upload resume in PDF format
- Extract text using PyMuPDF
- Detect skills from resume
- Compare resume with job description
- Calculate ATS score
- Provide improvement suggestions

## 🛠️ Tech Stack

- Python
- Flask
- PyMuPDF
- HTML
- CSS
